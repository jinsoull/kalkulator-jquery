# Kalkulator jQuery

Tugas PAW: aplikasi kalkulator berbasis web yang dibuat menggunakan jQuery.

## Ketentuan Tugas

1. Menampilkan NIM dan nama.
2. Mendukung operasi +, -, *, dan /.
3. Dibuat menggunakan jQuery.

## Teknologi

- HTML
- CSS
- JavaScript
- jQuery 3.7.0 (dimuat dari CDN)

## Struktur File

```
kalkulator-jquery/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
└── README.md
```

## Cara Menjalankan

1. Download atau clone repository ini.
2. Buka file `index.html` di browser.
3. Pastikan perangkat terhubung ke internet karena jQuery dimuat dari CDN.
